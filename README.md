# FSD-LAB-EXP

## Web Technology Lab Experiments

This repository contains 8 beginner-friendly Web Technology laboratory experiments, each created as a separate project inside the `WebTech-Lab-Experiments` folder.

## Experiments included

1. Student Grade Calculator
2. Online Ticket Booking Simulator
3. Personal Expense Tracker Utility
4. Student Profile Dashboard
5. Online Product Catalog
6. Course Registration Portal
7. Library Management REST API
8. Employee Management REST API

## How to use

Open the relevant experiment folder and follow the README instructions for that experiment. Each project is designed to be easy to explain during a lab examination and practical viva.

## Tech stack

- HTML5, CSS3, JavaScript ES6+
- React.js with Vite
- Node.js and Express.js
- REST API design and validation
- Responsive UI development
